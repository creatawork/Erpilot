# 工作台设计

面向订单、库存与报价操作，采用浅色工作台、紫色动作强调、清晰中文标签。保留业务状态和错误恢复路径。

- 会话历史固定在左侧；对话是中央主要任务区。
- 业务面板承载草稿、审批和结果，避免长表单打断消息阅读。
- 手机端使用抽屉，关闭后恢复触发按钮焦点；快捷入口纵向排列。
- 主题颜色、字号与控件尺寸由 src/theme.ts 管理，样式由 App.css 管理。
- 处理中、待审批、过期、失败、只读必须可区分；金额和库存来自服务端快照。
- 原始工具参数与结果放在折叠详情，审批展示用户需核对的实际影响。
- 尊重减少动态效果设置；保持键盘操作、明确标签和无横向页面溢出。
