# 订单与取消政策

订单状态流转与取消规则的统一口径。

## 订单状态

订单有六种状态：待付款、待发货、已发货、已签收、已取消、已退款。正常流程为待付款 → 待发货 → 已发货 → 已签收。新建订单从「待付款」起步。

## 可取消的订单

仅「待付款」或「待发货」的订单可直接取消。取消后系统会把订单内商品的库存**回补**。

## 已发货或已签收的订单

已发货、已签收的订单不可直接取消，需走退款流程处理（见退换货政策）。

## 销量与金额的有效口径

销量汇总与客户有效花费只统计「待发货 / 已发货 / 已签收」三种状态；已取消、已退款、待付款不计入有效销量口径。

## 建单规则

建单按现价生成快照价，校验商品在售与库存充足；同一 SKU 多行自动合并数量。库存不足时不建单，也不会把库存改为负数。
